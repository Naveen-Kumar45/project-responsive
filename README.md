# project-responsive
🍽️ Dineezy – Responsive Restaurant Website UI

📌 Overview
Dineezy is a basic responsive restaurant website UI built using HTML and CSS. This project focuses on designing a clean layout and navigation structure while applying fundamental frontend development concepts.

🚀 Features
Responsive design for mobile, tablet, and desktop
Clean and simple UI layout
Styled navigation bar
Structured sections (Home, Menu, About, Contact)
Beginner-friendly project

🛠️ Technologies Used
•HTML5
•CSS3
•Bootstrap 


📂 Project Purpose
This project was created to practice frontend development basics, including layout design, responsiveness, and styling using pure HTML and CSS.


⚠️ Note
This is a static UI project and does not include backend functionality or interactive features.
